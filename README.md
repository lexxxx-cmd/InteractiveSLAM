# Interactive SLAM

交互式位姿图（Pose Graph）编辑与回环闭合工具，基于 Qt6 Widgets + OpenSceneGraph 构建。支持加载 / 保存地图，交互式手动和自动回环检测与闭合，图优化，以及点云渲染控制。参考项目：https://github.com/koide3/interactive_slam

---

## 构建环境

### 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 (x64) |
| 编译器 | MSVC 2022 (Visual Studio 17 2022) |
| C++ 标准 | C++17 |
| CMake | ≥ 3.16 |
| 包管理器 | vcpkg (triplet: `x64-windows`) |

### vcpkg 依赖库

以下库通过 vcpkg 安装（`x64-windows` triplet）：

| 库 | 版本 | 说明 |
|------|------|------|
| `eigen3` | 5.0.1 | 线性代数（矩阵、向量、几何变换） |
| `pcl` | 1.15.1#1 | 点云库（io, common, search, features, registration） |
| `g2o` | 2024-12-28 | 图优化框架（自动安装 SuiteSparse 依赖） |
| `boost-filesystem` | 1.90.0#1 | 文件系统操作 |
| `osg` | 3.6.5#27 | OpenSceneGraph 3D 渲染引擎 |

安装命令：

```sh
vcpkg install eigen3 pcl g2o boost-filesystem osg --triplet x64-windows
```

### Qt6（官方安装）

Qt6 通过官方在线安装器安装，**非 vcpkg**（vcpkg 中 Qt6 编译耗时长且版本滞后）。

| 组件 | 版本 | 说明 |
|------|------|------|
| Qt 6.9+ (MSVC 2022 x64) | 6.9.1 / 6.10.2 | 基础框架 |
| Qt Widgets | — | GUI 控件库 |
| Qt OpenGL | — | OpenGL 支持模块 |
| Qt OpenGL Widgets | — | OpenGL 控件集成 |
| Qt Concurrent | — | 多线程并行（后台加载/优化） |
| Qt Linguist Tools | — | 国际化翻译工具 |

安装路径示例：`E:\ToolsApp\Qt\6.9.1\msvc2022_64`

> **注意**：CMake 通过 `CMAKE_PREFIX_PATH` 查找 Qt6，构建时需指定 Qt 安装路径。

### CMake 配置与构建

```sh
# 1. 进入项目目录
cd InteractiveSLAM

# 2. 创建构建目录
mkdir build && cd build

# 3. 配置（指定 Qt6 路径和 vcpkg toolchain）
cmake .. -DCMAKE_TOOLCHAIN_FILE="E:/vcpkg/scripts/buildsystems/vcpkg.cmake"

# 4. 构建（Release 模式）
cmake --build . --config Release

# 5. 运行
.\Release\appInteractiveSLAM.exe
```

> **建议**：将 `CMAKE_PREFIX_PATH` 和 `CMAKE_TOOLCHAIN_FILE` 配置到 CMakePresets.json 或系统环境变量中，避免每次手动输入。

### 可选依赖

| 库 | 说明 |
|------|------|
| OpenMP | 多线程并行（MSVC 自带，无需额外安装），启用 `ndt_omp` GICP/NDT 加速 |
| SuiteSparse | g2o 的稀疏矩阵求解器依赖，vcpkg 安装 g2o 时自动安装 |

## 文件菜单

| 操作 | 快捷键 | 说明 |
|---|---|---|
| 打开地图... | `Ctrl+O` | 选择地图文件夹，加载位姿图数据 |
| 关闭地图 | `Ctrl+W` | 关闭当前加载的地图 |
| 保存位姿图... | `Ctrl+S` | 将当前图保存为 `.g2o` 文件 |
| 保存地图... | `Ctrl+Shift+S` | 将地图（含点云数据）保存到指定目录 |
| 退出 | `Ctrl+Q` | 关闭程序 |

### 加载地图

1. 点击「文件 → 打开地图」或按 `Ctrl+O`
2. 选择包含 `graph.g2o` 和 `keyframes/` 等数据的地图文件夹
3. 加载完成后状态栏显示顶点数、边数和关键帧数 <!-- # 插图：打开地图对话框 -->

### 保存功能

- **保存位姿图** — 仅保存图结构（`.g2o` 文件），不含点云
- **保存地图** — 将完整地图（含点云）写入指定目录，同时自动在父目录生成 LVBA 格式的 `all_pcd_body/` 用于下游工具消费

#### LVBA 格式输出

保存地图时，并行生成以下 LVBA 兼容结构：

```
all_pcd_body/
├── lidar_poses.txt          # 所有关键帧位姿（TUM 格式：timestamp tx ty tz qx qy qz qw）
├── 000000.pcd               # 时序编号的点云文件（与 lidar_poses.txt 行号对应）
├── 000001.pcd
└── ...
```

- 点云从内存中的关键帧直接写入，使用 0.02m voxel 降采样版本
- 输出到保存目录的父目录下，与 dump 内容分离
- 生成失败不影响主保存流程

### 子图窗口大小

在进行回环闭合匹配时，软件可以将目标顶点附近的多个关键帧点云合并为一个子图进行配准，以提高匹配精度。

- **N = 1**（默认）：合并 3 个关键帧（中心-1，中心，中心+1）
- **N = 0**：仅合并选中的关键帧本身
- **N 最大 10**

## 回环闭合对话框

右键「回环起点」→「回环终点」后弹出，用于精细调整两个关键帧之间的相对位姿。

<!-- # 插图：回环闭合对话框 -->

### 区域说明

**1. 微型视口**
- 显示两个关键帧点云的叠加视图
- 源点云（白色）和终点云（按高程着色）
- 实时反映手动调整和自动配准的结果

**2. 配准评分**
- 实时显示当前的 `fitness_score` 值
- 评分越低表示匹配越好

**3. 手动调整**

| 控件 | 说明 |
|---|---|
| 步长选择 | `精细` / `中等` / `粗略` / `大步` 四档 |
| PX / PY / PZ | 沿局部坐标系平移（米） |
| RX / RY / RZ | 绕局部坐标系旋转（弧度） |

操作方式：拖动数值调整框，变化量自动累加到终点云的位姿上，调整框归零准备下一次调整。

**4. 操作按钮**

| 按钮 | 说明 |
|---|---|
| 自动对齐 | 使用 FPFH + SAC 全局配准自动对齐两帧点云 |
| 扫描匹配 | 使用 ICP / GICP / NDT 进行局部精配准 |
| 重置 | 将终点位置重置为打开对话框时的初始位姿 |
| 添加边 | 确认当前相对位姿，向图中添加（或更新）回环边并执行优化 |
| 取消 | 放弃本次回环操作 |

## 数据格式说明

程序加载的地图目录结构：

```
地图文件夹/
├── graph.g2o            # 位姿图文件（g2o 格式）
├── keyframes/            # 关键帧点云数据
│   ├── 000000.pcd        # PCD 格式点云
│   ├── 000001.pcd
│   └── ...
└── (data/)               # （可选）原始扫描数据
```

保存地图时，额外在上层目录生成 LVBA 兼容输出：

```
父目录/
├── 地图文件夹/           # dump 出的原始地图数据
└── all_pcd_body/         # LVBA 格式时序点云
    ├── lidar_poses.txt   # TUM 格式位姿文件
    ├── 000000.pcd
    └── ...
```

- **graph.g2o** — 标准 g2o 格式的位姿图文件，包含顶点位姿和边约束
- **keyframes/*.pcd** — PCL 的 PCD 格式点云文件，文件名与关键帧 ID 对应
- **all_pcd_body/** — 保存地图时自动生成的 LVBA 格式输出，供下游工具使用

## 提示

- 首次使用建议先打开一个已构建好的地图，熟悉界面布局
- 手动回环闭合建议先使用「自动对齐」（FPFH）获得初值，再用「扫描匹配」精配准
- 自动回环检测运行时，可以通过「回环边面板」实时查看和筛选已插入的边
- 渲染面板的「点透明度」配合 Z 轴裁剪可以有效观察地图内部结构
- 优化在后台线程执行，不会阻塞界面操作
